  Základy
  
Čtyři nápady, které řídí každý program.

  
Každý je jedna malá animace a jeden řádek kódu.

  

    

      1 · Proměnná
      
      
Krabička na hodnotu
Pojmenovaná krabice, do které se dá uložit číslo a kdykoli ho změnit.

      let zivoty = 3;
    

    

      2 · Podmínka
      
      
Rozcestí
Program se podívá na situaci a vybere si cestu.

      if (prsi) { vezmiDestnik(); }
    

    

      3 · Cyklus
      
      
Opakuj, nepiš znovu
Čtyři strany čtverce? Stačí říct, co dělat, a kolikrát.

      opakuj(4, () => …);
    

    

      4 · Funkce
      
      
Stroj na přání
Jednou ho postavíš, pak ho zavoláš, kolikrát chceš.

      function kresli(n) { … }
    

  






  Hřiště
  
Tvoje řada. Piš a spusť.

  
Želva jde dopředu a otáčí se, kam jí řekneš. Příkazy: vpred(délka), vpravo(úhel), vlevo(úhel), zvednout(), polozit(), domu(), opakuj(kolikrát, () => …). Jde i běžný JavaScript (for, if, function). Spuštění: Ctrl + Enter.
