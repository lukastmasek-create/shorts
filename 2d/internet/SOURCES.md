# InternetShort (#98 "What If You Could Enter the Internet?") — fact check
Checked by web search 2026-11-16. Several hits are secondary (marked). Premise ("websites as cities") is fiction; the short answers it with the physical internet.

|---|---|---|

## Do not claim
- exact "99%" share of cable traffic (secondary); total cable km above 1.4 M; number of cable systems (600-700, sources vary)
- ARPANET was built to survive nuclear war (disputed)
- cable thickness / "garden hose" (not verified)
- repair cost per fault (sources disagree)
- first website date (sources differ)
- "internet weighs/uses X" claims beyond the IEA figure
