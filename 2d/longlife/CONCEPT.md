# Concept — LongLifeShort
Candidates (all MONO, no faces, ~65 s):
1. **Ruler.** One 1,000-year bar. Human record fills 12% of it; shark, cells, limits mark it. Pro: one clear visual, every fact is a tick on one scale. Con: static if overused.
2. **Candle stack.** Lives as rows of candles/dots (1 dot = 10 years). Pro: simple. Con: weak fit for cell facts.
3. **Hourglass/timer.** Countdown clock per fact. Con: clocks already in `clocks`.

**Pick 1, the ruler.** Reason: sources are all numbers on one axis (50 divisions, 73, 122, 125–150, ~400, 1000), so the ruler IS the argument: "how far is 1,000 from where we are?". Ending: bar keeps going off-screen, ring pulse, iris.
Dropped: any "what society becomes" scene (no source).
