# Dim4Short — fact check (no invented claims)
Checked by web search 2026-11-14. Visuals of tesseract, slices, knot morph are computed geometry/schematic, not data.

| Claim in video | Source | Note |
|---|---|---|
| Eyes capture flat images, brain builds depth | standard vision science (retina is a 2D sheet; depth inferred, e.g. binocular disparity) | common knowledge, no single citation |
| Flatland 1884; sphere crossing a flat world appears as a circle that grows then shrinks | Abbott, *Flatland*, 1884 (chapter on the Sphere) | slice radius drawn = sqrt(R²−d²) |
| 4D object would appear as changing 3D slices | same analogy, one dimension up | geometric reasoning, not observation |
| Tesseract: 8 cubic cells, 24 square faces, 32 edges, 16 vertices | 8-cell / tesseract references (all agree) | animation is a true 4D rotation (XW + ZW planes) projected to 2D |
