# VirusShort (#89 "Shrink to the Size of a Virus") — fact check
Checked by web search 2026-11-16. Several hits were secondary (news/education pages); primary papers named so they can be opened. Ratios are arithmetic "illustrations", not measurements.

| Claim | Source | Note |
|---|---|---|
| SARS-CoV-2 particle is about 100 nm across (about 80 nm without spikes) | CDC Emerging Infectious Diseases 27(4) https://wwwnc.cdc.gov/eid/article/27/4/20-4337 ; Bar-On et al., "SARS-CoV-2 (COVID-19) by the numbers", eLife 2020 | measured range ~50–140 nm; say "about 100 nm" |
| Red blood cell is about 7–8 µm across | cell-size tables (Cornell SimScience, textbooks) https://sethna.lassp.cornell.edu/SimScience/membranes/intermediate/essay/cellsize1.html | secondary |
| Most animal cells are about 10–30 µm | cell-size tables, same family of sources | typical, not strict |
| E. coli is about 2 µm long, ~1 µm wide | cell-size tables, textbooks | length not diameter |
| Adult body: ~30 trillion human cells, ~38 trillion bacteria (same order of magnitude) | Sender, Fuchs & Milo, PLoS Biology 14(8):e1002533, 2016 | reference 70 kg man; script says "about thirty trillion cells, and about as many bacteria" |
| Visible light wavelength ~400–700 nm, so a ~100 nm virion is below it (no ordinary light microscope resolves it) | standard optics; wavelength range e.g. NASA/any physics text | secondary; stated as wavelength, not as a measured limit |
| Spike protein binds ACE2 to enter cells | Tocris viral cell entry https://tocris.com/research-area/viral-cell-entry ; Univ. Hamburg https://insidecorona.net/the-virus | secondary; also needs a host protease (TMPRSS2); endocytosis is one entry route |
| Virus uses the host cell's machinery (ribosomes) to copy itself | same sources + HHMI https://hhmi.org/beautifulbiology/scroll-and-tell/virus-behind-covid-19 | secondary |
| One infected cell releases "hundreds" of new virus copies | Scientific American "Inside the coronavirus" https://www.scientificamerican.com/interactive/inside-the-coronavirus/ | order of magnitude, varies by cell |
| 1.7 m / 100 nm = ~17 million; 7.5 µm / 100 nm = 75; 2 µm / 100 nm = 20; 10–30 µm / 100 nm = 100–300 | arithmetic | illustration; 1.7 m is an assumed adult height |

## Do NOT claim
- "Thousands" of virions per cell (only "hundreds" is sourced).
- Any virus count in the human body (no number verified).
- That viruses are 1,000x smaller than cells: typical human cell vs SARS-CoV-2 is ~100–300x.
- You would "see" anything: at 100 nm, below the wavelength of visible light (ordinary light microscopes cannot resolve it); scene is imagination only.
- Entry only by ACE2 (it is one route; other viruses use other receptors).
