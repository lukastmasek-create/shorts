# Why does popcorn pop? (particle swarm, 12 s)
60,000 glass beads, five beats, captions, synthesized sound. Uses `../ucimesehrou/src/stage.js` + `sound.js`.
- `src/style.js`: scene, schedule `T`, captions, score. `node build.cjs` -> `index.html` (player).
- MP4: `cd ../ucimesehrou && npm i && cd ../popcorn && node render.cjs 32` -> `video/popcorn.mp4` (GPU PC; 64 = full quality).
